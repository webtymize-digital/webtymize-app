# Webtymize Academy Mobil Uygulaması 📱

Webtymize Academy platformunun kullanıcılarına daha hızlı ve interaktif bir deneyim sunmak için geliştirilen resmi mobil uygulamasıdır. Bu uygulama ile eğitimlere erişebilir, sertifika doğrulayabilir ve akademi takvimini takip edebilirsiniz.

## ✨ Özellikler

* **Geniş Eğitim Kataloğu:** Dijital Pazarlama 101, Tasarım Temelleri ve daha fazlası.
* **Sertifika Doğrulama:** Aldığınız sertifikaları uygulama üzerinden anında sorgulayın.
* **Akademi Takvimi:** Canlı eğitim ve program tarihlerinden haberdar olun.
* **Destek Merkezi:** Ticket Form entegrasyonu ile taleplerinizi iletin ve takip edin.
* **Blog Erişimi:** Analizler, stratejik içerikler ve güncel haberler cebinizde.

## 🛠️ Teknolojiler

Uygulama modern ve performanslı bir deneyim için aşağıdaki teknolojilerle inşa edilmiştir:

* **Framework:** React Native / Expo (veya kullandığın ana framework)
* **UI/Styling:** Tailwind CSS / NativeWind
* **Backend Entegrasyonu:** .NET Core & Firebase
* **State Management:** Redux Toolkit / Context API

## 🚀 Kurulum

Uygulamanın en güncel sürümünü kullanmak için aşağıdaki adımları izleyebilirsiniz:

1.  **Releases** sekmesine gidin.
2.  En son yayınlanan sürüm (Latest) altındaki `.apk` (Android) veya ilgili kurulum dosyasını indirin.
3.  Cihazınıza kurulumu tamamlayın.
